# designspark-website

Website for DesignSpark.

## Design style skills

This repo includes 10 website design style skills for Claude Code in `.claude/skills/`.
Ask for a style by name, e.g. *"Build the homepage in Glassmorphism"*.

| # | Style | Look |
|---|-------|------|
| 1 | Skeuomorphism | Realistic textures and materials (wood, leather, brass) |
| 2 | Neumorphism | Soft dual shadows, raised/inset elements on one surface |
| 3 | Glassmorphism | Translucent frosted-glass panels over colourful backgrounds |
| 4 | Claymorphism | Puffy 3D clay shapes, bright playful colours |
| 5 | Brutalism | Raw, high contrast, bold type, black borders, hard shadows |
| 6 | Minimalism | Clean type, lots of whitespace, few elements |
| 7 | Maximalism | Bold colours, patterns, layered collage visuals |
| 8 | Liquid Glass | Glossy translucent fluid glass with reflections |
| 9 | Bento Grid | Modular rounded tiles in a structured grid |
| 10 | Spatial UI | Floating panels, depth and perspective |
